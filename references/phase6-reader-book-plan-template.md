# Phase 6 读者手册书级路线计划模板

本表用于先定读者的目录与学习依赖，再从 curriculum units、冻结源码和已接受证据中选取所需材料。unit 是证据输入，不是目录；一个主题可以综合多个 unit，一个 unit 也可以服务多个主题。按学习结果和篇幅拆分，不固定章数。本计划供人编排和复核，不是全局 schema 或自动深度判定。

## 读者与全书路线

- **默认读者及假定知识：** 初学者；列出不可默认读者已懂的项目/语言/框架概念。
- **要理解的项目及证据版本：** 填写本次目标项目、源码 revision/快照及主要输入版本；其他项目不得沿用 Ragent 示例值。
- **读完全书应能做到：**
- **本册包含与不包含的范围：**
- **范围状态：** 分别标出已有读者稿、待编主题、未验证或未知；Phase 6 初版不得冒称覆盖了项目全部功能，Phase 7–12 不在本轮授权内。
- **贯穿全册的功能场景与假设输入：** 说明用户、业务问题、输入值和预期可观察结果；教学假设须明确标记。
- **全景图职责：** 展示整个项目已知业务/架构边界；缺证连接如何显示为未知。
- **功能图职责：** 展示贯穿功能的用户步骤、代码职责、数据交接和中间状态；它不取代逐段源码教学。
- **读者交付目录与文件约定：** 由本次书级计划指定；例如当前 Ragent 实例使用 `D:/学习教材/Ragent/项目深读教材/`。成品平铺顺序编号的中文 Markdown，每章把完整答案放在正文练习之后。

### 主题卡（每个读者主题各填一份）

- **主题标题与准确目录位置：**
- **最终中文文件名及前后章链接：**
- **它为何在这里：** 读者从哪些已学内容进入，下一主题依赖什么结果。
- **本主题应能完成的 1–3 个具体动作：** 写解释、推演、预测、诊断等可观察行为；这只是切分建议，不是深度上限。
- **本主题使用的 unit ID 与来源：** 每项只说明它贡献的事实/证据，不将 unit 次序当作读者次序。
- **前置概念：** 写出首次依赖概念的位置和就地解释方式；如有延后项，填写精确后续文件/节链接及仍未达成的学习结果。
- **贯穿场景：** 继承全书输入；若短暂换成纯教学例子，说明原因并立即映射回主线。
- **输入到结果的步骤：** 每步列出假设/实测输入、状态变化、可观察中间结果和下一跳；区分源码推演与运行证据。
- **图的用途：** 本主题画全景图还是功能局部图？文字怎样解释图中边界？Mermaid 无法渲染时的文本说明是什么？
- **源码角色：** 对本主题关键源码逐个分类。只给文件/行号的是导航，不算完成教学。

| 关键行为/来源 | 角色 | 本章必要片段与解释位置 | 职责、输入、处理、输出、下一跳 | 准确后续位置（若延后） |
| --- | --- | --- | --- | --- |
|  | 正文主讲 / 就地支持 / 纯导航 / 延后深读 |  |  |  |

- **失败与验证：** 选取能影响学习结果的失败边界，说明该检查能证明什么、不能证明什么；把可推导、拟议测试、实际运行和外部读回分开。
- **练习和完整答案：** 完整答案紧接本章正文中的练习，并使用相同输入展示关键判断、数据变化、最终结果和为何其它分支不成立；短代码/结果直接入正文，长演示使用纯 Markdown 附录。
- **未知和延后目标：** 说明它影响哪些学习结果、是否阻塞本主题；不能因排进后续而标成当前已学会。

## 源码呈现规则

- **正文主讲：** 在本章给必要源码片段；解释角色、输入、处理、输出与下一跳，并用贯穿输入演算。
- **就地支持：** 本章给闭合当前因果所需的小片段和说明；完整机制可在链接到的主题深读。
- **纯导航：** 只提供路径、符号和精确行号供查证；它不承担教授该行为，也不能支撑该学习结果已完成。
- **延后深读：** 给可解析的教材文件与节标题/链接，并指出仍待达到的结果；当前依赖它的学习结果保持 PENDING。

总览可以先给整体图，再讲少量关键片段；不要把全项目实现堆入总览。凡主题依赖源码说明关键架构/业务行为，就在该主题呈现必要片段并解释，不让初学者按长路径索引自行寻找和拼接。源码位置用于验证与回查，不能代替教学。

## 全书闭环检查

- 目录先解释整体目的和业务，再放大架构与完整功能，最后进入机制、失败和验证。
- 全书例子是否沿用同一输入，并给每个交接可见的中间结果？
- 每个关键架构/业务结论是否在教学主题中有源码片段、因果解释和准确定位？
- 框架/手写模型是否只声称其实际演示的机制？例子是否说明可运行性与省略项？
- 重要失败分支、验证方法、完整答案是否与正文同一逻辑？
- 所有未知与延后结果是否仍清晰可见，没有从 PENDING 自动变成完成？

此计划帮助人决定“按什么路线教、当前还没教会什么”。哈希、定位和工具验证不能自动判断初学者是否真正理解；整书教学仍须由独立读者复核。
