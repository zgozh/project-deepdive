# 直接读源码的教学路径

当目标项目没有可用适配器、提取结果不完整，或没有本 Skill 正式读者生命周期所需的已认证输入时，使用本路径。它允许作者依据实际项目文件写出诚实、可独立审阅的教学稿，不生成正式生命周期回执。工具缺失不阻止起稿，也不允许补造事实。

先按用户请求选择一条路径：只有用户要求绑定或发布正式读者产物、且正式计划与源码前置条件齐备时，才走已认证生命周期；其他起稿和解释任务可直接使用本指南。用户没有要求验证时，不因本路径而编译、运行生命周期或执行目标项目测试。

开始前读取本指南及包内的[源码主题写作卡](phase6-source-topic-writing-card.md)、[读者手册契约](phase6-reader-handbook-contract.md)和[学习者 AI 协作卡](learner-ai-collaboration-card.md)，再按主题读取所需的目标文件。无需先运行 AST、图谱、课程提取，也不依赖其他 Skill、网页或当前对话中的隐含约定。

开始写入章节 Markdown 时，若宿主可能误解释引号、反引号、`${...}`、`$()` 或中文，可按需参考[作者写入传输指南](authoring-transport-guide.md)。这是可选的本地写入实践，不要求每章重复探针。

## 固定实际读到的源码

先确定一个学习问题和有限主题，记录目标根目录、问题及不覆盖的范围。讲清一个主题不代表覆盖整个仓库。

**Git revision（版本标识）**是精确选中的提交或其他 Git 版本对象；**工作树（worktree）**是磁盘上的检出文件，可能含未提交修改；**SHA-256**是对确切字节计算出的摘要，不是 Git revision，也不是摘要说明。

若用已提交版本，先解析并记录所选 revision 的完整值。每个目标文件都从该版本对象读取，例如：

```text
git show <revision>:<仓库相对路径>
```

SHA-256 必须对同一对象输出的原始字节计算。将下面的自包含脚本保存为 UTF-8 文件 `hash_git_blob.py`，从目标仓库根目录启动；revision 和仓库相对路径分别作为参数传入，Git 输出以原始字节交给哈希函数。启动命令中的 `REVISION` 和 `REPO_RELATIVE_PATH` 是需要替换的参数：

```python
import hashlib
import subprocess
import sys

revision, path = sys.argv[1:3]
raw_bytes = subprocess.check_output(["git", "show", revision + ":" + path])
print(hashlib.sha256(raw_bytes).hexdigest())
```

```text
python hash_git_blob.py REVISION REPO_RELATIVE_PATH
```

不要在 shell 参数里内嵌整段 Python，也不要先把 Git 输出解码或经文本管道重编码。

不要只记录 `HEAD`，随后却从可能含脏改动的工作树路径读文件；那样 revision 与实际教学依据并不绑定。

若依据工作树或没有 Git，冻结实际读到的少量相关文件字节：可保留这些文件的只读副本，或使用能保证复核期间字节不变的文件快照；对同一份字节计算 SHA-256。记录真实路径、行号范围和摘要。文件改变或无法确认复核者读到同一字节时，重新固定并复核该来源。不要为此复制整仓库或建立大型缓存。

沿主题定位入口、完整定义、调用方与被调用方、配置和邻近失败处理。记录实际读取的路径与行范围。大文件只依据已完整读到的必要定义和交接点缩小主题；工具预览被截断时，按文件或分段继续读取，不能把截断内容当全文。无法从静态源码确认的运行时接线写成 `UNKNOWN`，同时说明源码能证实什么。

## 按完整教学深度写作

起稿前逐项应用源码主题写作卡的全部 17 项职责。没有适配器、蓝图或正式教材，不会减少任何一项。某项确实不适用时，说明原因；证据不足和未知行为仍要明确标记。

面向真正的初学者，按这个次序展开：直觉、前置概念、项目与业务背景、架构、源码、机制、失败和扩展。术语先定义，再使用；先说明场景，再讲代码。沿真实调用过程解释调用者、输入、关键值与条件、返回或交接，以及下一步。

正式读者源码呈现由 `reader_source_blocks.py` 自动为每块生成唯一的 `源码位置` caption；沿用它，不要手写重复 caption。直接读源码起稿时，也可选择复用[独立 renderer](../scripts/reader_source_blocks.py) 的 `render_source_block(source_bytes, *, path, start_line, end_line, language, expected_source_sha256=None, expected_excerpt_sha256=None, revision=None)`：传入已固定的完整目标文件原始字节和该文件中的绝对起止行号，一次生成 caption 与所选原代码，并返回不含源码正文的 provenance，按需保留在作者目录。不要把局部快照伪装成完整文件字节。此 renderer 是可选呈现工具，不要求正式读者生命周期，不生成正式 receipt 或语义 PASS，也不限制正文展开；工具不可用时，仍可手写路径与行号。无论哪种方式，每个 caption 只生成一次；路径、caption 和行号表须对应完整展示的源码行。caption 只用于定位，不是来源回执，也不代表来源或教学复核 PASS。组装最终章时，直接沿用同一份冻结来源对应的 caption 与代码块原字节（包括缩进和空行），不要重新键入、strip 或格式化；renderer 准备结果不证明最终章，最后一次局部来源核对必须以已组装的最终章为对象。

若保留了 renderer provenance JSON 数组，可选在最终章组装后，从已安装的 Skill 根目录运行 `python scripts/verify_reader_source_blocks.py --chapter <章节.md> --provenance <provenance.json>`。它只核对所列块在最终稿中的渲染字节和 overlay 移除后的摘录摘要；手工摘录、源码身份、正文解释与教学质量均不在核对范围内，也不构成正式回执或 PASS。此便利检查不要求正式生命周期，也不限制手工摘录路径或正文展开。

每个选用的源码块保留实际来源的全部行和原始行号，不用省略号代替源码。它的自适应逐行表要覆盖展示的每一行；只有职责相同的相邻行才可合并。代码块之前讲清角色、调用方、场景和输入；块内解释关键语句、值、分支、调用、返回与错误；块后用同一输入重走结果和下一次交接。值流讲解要区分本地生成的值、传入调用的参数、被接收使用的返回值和被忽略的返回值；回放、伪代码和答案按源码的真实副作用顺序展开。前置 guard 只写源码实际检查的条件，并保留它所在的层次与位置。逐行表是讲解辅助，不是正确性证明。围绕一个主题深入，不要把有界讲解变成仓库清单。

正文叙述、练习和答案（包括 AI 材料）的源码行引用也使用仓库原文件行号；片段内部序号不能冒充原文件行号。架构图的箭头要区分源码证实的调用/数据返回与教学假设；未核实的 UI→API 关系用虚线标出或与真实链路分开。对于已追踪的实际请求，服务端处理和响应应回到发起该请求的 caller；不要跳过中间的刷新/查询请求，再把后端连到另一条假设 API。

图中标出的实际类名和方法名要与源码一致；字段值表按真实字段逐列对应，不同字段不能用“同左”混写。校验说明只覆盖源码实际检查的条件：例如非空检查只证明非空，不证明值属于合法成员。

解释机制；源码足以支持时，再给出最小的非框架等价实现和权衡。区分源码事实、通用原理、解释性判断和运行时未知。练习必须给完整答案，且答案与正文推演一致。使用协作卡显式暴露假设并挑战调用轨迹；AI 建议在逐条绑定到证据前都未验证。

## 分开复核来源与教学

保留一份简明来源记录：目标 revision 或文件字节 SHA-256、选中路径与行范围、支持的主张、作者和未知项。来源复核者检查路径、值、交接与主张是否符合这些确切字节，并记录复核结果和未检查范围；也核对正文、练习、答案和图中的原文件行号与请求箭头是否对应实际源码和同一调用链。

另由独立于作者和来源复核者的教学复核者（另一位人类，或真正独立的 AI 上下文）读取最终全文及每个完整答案。将教学复核绑定到最终稿 SHA-256；检查前置知识与顺序、源码前/中/后的解释、证据支持的正常与失败轨迹、答案一致性，并记录范围、遗漏范围、教学缺口和未知项。仅换 session ID、计算哈希或做完整行表，都不能构成独立语义教学复核。

分别报告两个结论：来源复核检查来源与事实是否对齐；教学复核判断初学者能否从这份确切稿件学会内容，二者不可互相替代。人工审过的草稿可在明确限制下用于学习。本路径不发 `READER_REVIEWED_DRAFT` 回执，也不伪造命令记录；模板、哈希或结构检查不能升级状态。若用户要求正式发布而已认证输入缺失，明确指出前置缺口，并保留诚实的草稿状态。

将方括号替换成目标项目的真实路径和主题。以下是提示模板，不是已执行的命令，也不证明源码已读取或复核已完成。

**作者提示**

**独立来源复核提示**

**独立教学复核提示**
